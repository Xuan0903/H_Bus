## 功能概述

排班調度管理系統提供彈性的排班新增功能，支援：
- **Excel 資料整合**：特定路線可從 Excel 自動載入發車時間和駕駛員資訊
- **手動輸入**：支援手動輸入所有必要資訊
- **互斥機制**：Excel 選擇與手動輸入互相排斥，避免資料混淆
- **智慧驗證**：自動檢查時間、車輛、駕駛員衝突

## 路線選擇

### 操作步驟
1. 點擊「新增排班」按鈕開啟新增視窗
2. 在「路線編號」下拉選單中選擇要排班的路線

### 路線類型說明

#### Excel 路線
- **路線 1**：市民小巴5
- **路線 2**：市民小巴6
- **路線 3**：市民小巴7

這些路線支援從 Excel 檔案載入發車時間資料。

#### 非 Excel 路線（路線 4、18 等）
- **路線 4**：行動遊花蓮
- **路線 18**：其他路線

這些路線需要手動輸入所有資料。

### 自動行為
- 選擇路線後，系統會自動判斷是否為 Excel 路線
- Excel 路線會啟用營運型態下拉選單
- 非 Excel 路線的營運型態改為自由文字輸入

## 方向選擇

### 選項說明
- **去程**：從起點到終點
- **返程**：從終點返回起點
- **其他**：特殊路線或循環路線

### 必填條件
- **正常營運狀態**：必須選擇方向
- **暫停營運/維修中**：方向為選填

### Excel 路線特殊邏輯

#### 市民小巴5 和 市民小巴6（路線 1、2）
- 必須選擇「去程」或「返程」
- 系統會根據選擇的方向載入對應的 Excel 工作表
- 預設自動選擇「去程」

#### 市民小巴7（路線 3）
- **不分方向**
- 此路線在 Excel 中只有一個工作表
- 不需要選擇方向即可載入發車時間

## 營運型態設定

### Excel 路線的營運型態（下拉選單）

當選擇路線 1、2、3 時，營運型態為下拉選單，包含：

#### 選項
1. **平日**：週一至週五的一般營運
2. **假日**：週六、週日
3. **寒暑假**：學校寒暑假期間的特殊班次

#### Excel 工作表對應關係

系統會根據「營運型態」、「路線」和「方向」組合成 Excel 工作表名稱：

**格式規則：**
- 市民小巴5/6：`{營運型態}-{路線名稱}({方向})`
- 市民小巴7：`{營運型態}-{路線名稱}`

**範例：**
- `平日-市民小巴5(去程)` - 平日的市民小巴5去程班次
- `假日-市民小巴6(回程)` - 假日的市民小巴6返程班次
- `寒暑假-市民小巴7` - 寒暑假的市民小巴7班次（不分方向）

#### 載入順序
發車時間的載入需要按照以下順序選擇：
1. 先選擇「路線編號」
2. 再選擇「營運型態」
3. 對於市民小巴5/6，還需選擇「方向」
4. 完成上述步驟後，系統自動載入發車時間選項

### 非 Excel 路線的營運型態（文字輸入）

當選擇路線 4、18 等非 Excel 路線時：
- 營運型態為自由文字輸入欄位
- 可填寫任意文字描述
- 範例：「假日班次」、「夜間專車」、「特殊活動」等

### 必填條件
- **正常營運狀態**：Excel 路線必須選擇營運型態
- **暫停營運/維修中**：營運型態為選填

## 營運狀態選擇

### 選項說明

#### 1. 正常營運
- 完整的排班，需填寫所有必要資訊
- **必填欄位**：
  - 路線編號
  - 往/返/其他（方向）
  - 營運型態（Excel 路線）
  - 日期
  - 發車時間
  - 牌照號碼
  - 駕駛員姓名
  - 員工編號

#### 2. 暫停營運
- 表示該路線/時段暫停服務
- **必填欄位**：
  - 路線編號
- **選填欄位**：
  - 方向
  - 營運型態
  - 日期（可記錄暫停日期）

#### 3. 維修中
- 表示車輛正在維修，無法派車
- **必填欄位**：
  - 路線編號
- **選填欄位**：
  - 方向
  - 營運型態
  - 日期（可記錄維修日期）

### 自動清空機制
當營運狀態從「正常營運」切換為「暫停營運」或「維修中」時，系統會自動清空：
- 日期
- 發車時間
- 車牌號碼
- 駕駛員姓名
- 員工編號

## 日期與發車時間

### 日期選擇
- 使用日期選擇器輸入排班日期
- 格式：YYYY-MM-DD
- 正常營運狀態必填

### 發車時間設定

系統提供兩種發車時間輸入方式，**兩者互斥**：

#### 1. Excel 發車時間（Excel 路線專用）

**適用範圍：**
- 僅限路線 1、2、3（市民小巴5、6、7）

**啟用條件：**
必須完成以下步驟才能選擇：
1. 選擇路線編號
2. 選擇營運型態（平日/假日/寒暑假）
3. 選擇方向（市民小巴5、6需要；市民小巴7不需要）

**使用方式：**
- 從下拉選單中選擇預先設定好的發車時間
- 時間來源：`Departure_Time.xlsx` 檔案
- 時間格式：HH:MM（例如：08:30、14:45）

**提示訊息：**
- 「請先選擇路線」- 未選擇路線時
- 「請先選擇營運型態」- 未選擇營運型態時
- 「請先選擇方向」- 市民小巴5/6未選擇方向時
- 「載入中...」- 正在從 Excel 載入資料時
- 「已選擇手動輸入」- 已在手動輸入欄位填寫時間時

#### 2. 手動發車時間

**適用範圍：**
- 所有路線都可使用
- 非 Excel 路線（路線 4、18 等）只能使用此方式

**使用方式：**
- 使用時間選擇器輸入
- 格式：HH:MM（24小時制）
- 可精確到分鐘

**提示訊息：**
- 「已選擇Excel時間」- 已在 Excel 下拉選單選擇時間時

#### 互斥機制

**Excel 發車時間 → 手動發車時間：**
- 當在 Excel 下拉選單選擇時間時
- 手動發車時間欄位自動清空並禁用
- 顯示 placeholder：「已選擇Excel時間」

**手動發車時間 → Excel 發車時間：**
- 當在手動欄位輸入時間時
- Excel 下拉選單自動清空並禁用
- 顯示選項：「已選擇手動輸入」

#### 最終時間判斷
系統儲存時的優先順序：
```
最終發車時間 = Excel發車時間 || 手動發車時間
```

## 車輛選擇

### 選擇方式
從「牌照號碼」下拉選單中選擇可用車輛

### 車輛狀態說明
系統只顯示**狀態為「service」（服務中）**的車輛：
- **service**：正常服務中，可派車
- **paused**：暫停使用（不顯示）
- **maintenance**：維修中（不顯示）
- **retired**：已退役（不顯示）

### 顯示格式
```
車牌號碼 (車輛狀態)
```
例如：`ABC-1234 (service)`

### 必填條件
- **正常營運狀態**：必須選擇車輛
- **暫停營運/維修中**：不需要選擇車輛

## 駕駛員選擇

系統提供兩種駕駛員資訊輸入方式，**兩者互斥**：

### 1. Excel 駕駛員選擇

**資料來源：**
- 來自 `Drivers_Info.xlsx` 檔案
- 包含欄位：Driver_name（駕駛員姓名）、Employee_number（員工編號）

**使用方式：**
1. 從「駕駛員選擇(Excel)」下拉選單中選擇駕駛員
2. 系統自動填入：
   - 駕駛員姓名(手動)
   - 員工編號(手動)
3. 手動輸入欄位會自動禁用

**顯示格式：**
```
駕駛員姓名 (員工編號)
```
例如：`張小明 (E12345)`

**清除選擇：**
- 選擇「請選擇駕駛員」選項
- 系統會清空駕駛員姓名和員工編號欄位
- 手動輸入欄位恢復可用

### 2. 手動輸入駕駛員

**使用時機：**
- Excel 中沒有該駕駛員資料
- 臨時駕駛員
- 新進駕駛員尚未加入 Excel

**輸入欄位：**
1. **駕駛員姓名(手動)**
   - 輸入駕駛員的完整姓名
   - 正常營運時為必填

2. **員工編號(手動)**
   - 輸入駕駛員的員工編號
   - 正常營運時為必填

**互斥機制：**
- 當在手動欄位輸入任何內容時
- Excel 下拉選單自動禁用
- 顯示：「已選擇手動輸入」

### 互斥邏輯說明

#### Excel 選擇 → 手動輸入
```
當選擇 Excel 駕駛員時：
1. 自動填入駕駛員姓名和員工編號
2. 手動輸入欄位禁用（disabled）
3. 背景變灰，無法編輯
```

#### 手動輸入 → Excel 選擇
```
當在手動欄位輸入時：
1. Excel 下拉選單禁用
2. 顯示「已選擇手動輸入」
3. 無法從下拉選單選擇
```

### 必填邏輯（正常營運狀態）

**情況 1：使用 Excel 選擇**
- 必須從 Excel 下拉選單選擇駕駛員
- 選擇後自動滿足姓名和員工編號必填要求

**情況 2：使用手動輸入**
- 駕駛員姓名：必填
- 員工編號：必填
- 兩者都必須填寫

**情況 3：混合使用（不允許）**
- 系統強制互斥，無法同時使用兩種方式
- 必須選擇其中一種方式完整填寫

## 衝突檢查機制

系統在儲存前會自動檢查以下衝突情況（僅限正常營運狀態）：

### 1. 車輛衝突
**檢查條件：**
- 相同車牌號碼
- 相同日期
- 相同發車時間

**錯誤訊息：**
```
車牌 ABC-1234 在 2025-01-15 08:30 時段已有排班
```

### 2. 駕駛員姓名衝突
**檢查條件：**
- 相同駕駛員姓名
- 相同日期
- 相同發車時間

**錯誤訊息：**
```
駕駛員 張小明 在 2025-01-15 08:30 時段已有排班
```

### 3. 員工編號衝突
**檢查條件：**
- 相同員工編號
- 相同日期
- 相同發車時間

**錯誤訊息：**
```
員工編號 E12345 在 2025-01-15 08:30 時段已有排班
```

### 衝突處理
- 如果發現任何衝突，系統會阻止儲存
- 彈出警告視窗顯示所有衝突項目
- 使用者需要修改資料後才能繼續

### 注意事項
- **允許同一路線在不同時間多次排班**
- 暫停營運和維修中狀態不進行衝突檢查
- 編輯現有排班時，會排除該筆記錄本身

## 連續新增功能

為了提高排班效率，系統支援連續新增模式：

### 運作方式

#### 新增模式
當成功新增一筆排班後：
1. **模態框保持開啟**（不關閉視窗）
2. **保留以下欄位的值**：
   - 路線編號
   - 往/返/其他（方向）
   - 營運型態
   - 營運狀態
3. **清空以下欄位**：
   - 日期
   - 發車時間（Excel 和手動）
   - 牌照號碼
   - 駕駛員選擇
   - 駕駛員姓名（手動）
   - 員工編號（手動）
4. **重新載入發車時間選項**（如果是 Excel 路線）

#### 編輯模式
編輯現有排班時：
- 更新成功後**自動關閉模態框**
- 返回列表頁面

## 完整操作流程範例

### 範例 1：Excel 路線正常排班

**需求：** 新增市民小巴5平日去程 08:00 班次

```
1. 點擊「新增排班」
2. 路線編號：選擇「1 - 市民小巴5」
3. 往/返/其他：自動選擇「去程」（可調整）
4. 營運型態：選擇「平日」
   → 系統自動載入「平日-市民小巴5(去程)」的發車時間
5. 營運狀態：選擇「正常營運」
6. 日期：選擇「2025-01-15」
7. 發車時間(Excel)：選擇「08:00」
8. 牌照號碼：選擇「ABC-1234 (service)」
9. 駕駛員選擇(Excel)：選擇「張小明 (E12345)」
   → 自動填入駕駛員姓名和員工編號
10. 點擊「新增」
11. 儲存成功，視窗保持開啟
12. 繼續新增下一個班次或點擊「取消」關閉
```

### 範例 2：非 Excel 路線正常排班

**需求：** 新增行動遊花蓮班次

```
1. 點擊「新增排班」
2. 路線編號：選擇「4 - 行動遊花蓮」
3. 往/返/其他：選擇「去程」
4. 營運型態：手動輸入「假日專車」
5. 營運狀態：選擇「正常營運」
6. 日期：選擇「2025-01-20」
7. 發車時間(Excel)：顯示「此路線無Excel資料，請使用手動輸入」
8. 發車時間(手動)：輸入「09:30」
9. 牌照號碼：選擇「XYZ-5678 (service)」
10. 駕駛員姓名(手動)：輸入「李四」
11. 員工編號(手動)：輸入「E67890」
12. 點擊「新增」
```

### 範例 3：暫停營運排班

**需求：** 記錄市民小巴6某日暫停營運

```
1. 點擊「新增排班」
2. 路線編號：選擇「2 - 市民小巴6」
3. 往/返/其他：選擇「去程」（選填）
4. 營運型態：選擇「平日」（選填）
5. 營運狀態：選擇「暫停營運」
   → 系統自動清空時間、車輛、駕駛員欄位
6. 日期：選擇「2025-01-16」（選填，用於記錄暫停日期）
7. 點擊「新增」
```

### 範例 4：維修中排班

**需求：** 記錄市民小巴7維修中

```
1. 點擊「新增排班」
2. 路線編號：選擇「3 - 市民小巴7」
3. 營運狀態：選擇「維修中」
   → 系統自動清空相關欄位
4. 日期：選擇「2025-01-17」（選填，記錄維修開始日期）
5. 點擊「新增」
```

## 常見問題 FAQ

### Q1：為什麼發車時間下拉選單無法選擇？
**A1：** 請檢查是否完成以下步驟：
1. 已選擇路線（且為 Excel 路線：1、2、3）
2. 已選擇營運型態（平日/假日/寒暑假）
3. 市民小巴5/6 需選擇方向
4. 確認未在「發車時間(手動)」欄位輸入內容

### Q2：Excel 駕駛員下拉選單為什麼被禁用？
**A2：** 因為已在「駕駛員姓名(手動)」或「員工編號(手動)」欄位輸入內容。兩種輸入方式互斥，需先清空手動輸入欄位。

### Q3：如何使用手動輸入而不是 Excel 選項？
**A3：** 
- **發車時間**：直接在「發車時間(手動)」欄位輸入，Excel 下拉選單會自動禁用
- **駕駛員**：直接在「駕駛員姓名(手動)」和「員工編號(手動)」欄位輸入

### Q4：為什麼出現衝突警告？
**A4：** 系統檢測到同一時段、同一車輛或駕駛員已有排班。請檢查：
- 車牌號碼是否重複使用
- 駕駛員是否同時段重複排班
- 員工編號是否正確

### Q5：市民小巴7 為什麼不需要選擇方向？
**A5：** 市民小巴7 是單向路線或循環路線，在 Excel 中只有一個工作表，不區分去程回程。

### Q6：暫停營運還需要填寫發車時間嗎？
**A6：** 不需要。選擇「暫停營運」或「維修中」後，系統會自動清空並不要求填寫時間、車輛和駕駛員資訊。

### Q7：如何修改已保存的排班？
**A7：** 在排班列表中點擊該筆記錄的「編輯」按鈕，修改後點擊「更新」。

### Q8：新增成功後為什麼視窗沒有關閉？
**A8：** 這是連續新增功能，方便您快速新增多筆相似排班。完成所有新增後，點擊「取消」按鈕關閉視窗。

### Q9：Excel 路線和非 Excel 路線有什麼區別？
**A9：**
- **Excel 路線（1、2、3）**：可從 Excel 選擇發車時間和駕駛員，也可手動輸入
- **非 Excel 路線（4、18 等）**：所有資訊都需手動輸入

### Q10：如何知道哪些車輛可以使用？
**A10：** 系統只顯示狀態為「service」的車輛。如果需要的車輛未出現在列表中，請先在「車輛管理」中確認車輛狀態。

## 注意事項

1. **資料同步**
   - Excel 檔案（Departure_Time.xlsx、Drivers_Info.xlsx）需要先準備好
   - 修改 Excel 檔案後需重新載入頁面
   - 確保 Excel 工作表命名符合系統規則

2. **權限要求**
   - 需要登入系統才能新增排班
   - 確認您的帳號有排班管理權限

3. **營運狀態選擇**
   - 正常營運：完整排班，需填寫所有必要資訊
   - 暫停營運：記錄路線暫停，無需詳細資訊
   - 維修中：記錄維修狀態，無需詳細資訊

4. **時間格式**
   - 日期格式：YYYY-MM-DD
   - 時間格式：HH:MM（24小時制）
   - 確保時間輸入正確，避免排班錯誤

5. **衝突預防**
   - 同一時段避免重複使用相同車輛
   - 同一時段避免重複安排相同駕駛員
   - 系統會自動檢查並提示衝突

6. **連續新增建議**
   - 適合同一路線多個班次的快速排班
   - 建議先規劃好排班表再進行連續新增
   - 可以隨時點擊「取消」結束連續新增

### 後端 API
- `GET /api/schedules/routes`：取得可用路線列表
